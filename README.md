# Midnight Club: L.A. Remix (USA) — PSP Static Recompilation

Statically recompile Midnight Club: L.A. Remix (USA) (PSP) into a native
aarch64 executable for the R36S (RK3326, Mali-G31 MP2, 1GB RAM, ArkOS/
dArkOS Enhanced) using [psprecomp](https://github.com/sp00nznet/psprecomp)
(v0.5.0, MIT) and package it as a PortMaster port.

### Milestone 2 — crash fix needed

The game segfaults before the title screen due to C stack overflow from
mutual tail recursion (`0x2EE75C` ↔ `0x2EF5CC`). The emitter compiles tail
calls as plain C calls without tail-call elimination. Fix: tail-call
optimization in `src/psprecomp/tools/allegrexrecomp/emit.c`.

## Building

### Host build (testing, no device needed)

```sh
cd "/home/amarqs/recomp projects/Midnight Club - L.A. Remix (USA)"
export PATH="$HOME/.local/share/mise/installs/cmake/4.4.5/cmake-4.4.5-linux-x86_64/bin:$HOME/.local/share/mise/installs/ninja/1.13.2/bin:$PATH"
cmake -S . -B build -G Ninja -DPPSPRECOMP_REAL_THREADS=ON
cmake --build build -j8 --target mc3
```

### aarch64 cross build (for R36S)

```sh
cmake -S . -B build-aarch64 -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=<your-aarch64-toolchain> \
  -DPPSPRECOMP_REAL_THREADS=ON
cmake --build build-aarch64 -j6 --target mc3
cp build-aarch64/src/mc3/mc3 ports/midnight-club-lar/mc3
```

## Running (host)

```sh
./build/src/mc3/mc3 -e <decrypted-EBOOT.ELF> -r gles32
```

Options:
- `-e <ELF>`: path to decrypted EBOOT.ELF (required)
- `-r <backend>`: software (default), gles32, null

## PortMaster port

The PortMaster port lives at `ports/midnight-club-lar/`. Copy the built
`mc3` binary into that directory, place your decrypted `EBOOT.ELF` where the
launch script can find it, and launch through the PortMaster GUI.

**Never** put game files (ISO, ELF, PRX, assets) in this repo or the port.

## Reverse-engineering tools

RE tooling (Ghidra projects, REA logs, GhidraMCP sessions) lives in `scratch/`
and is gitignored. These are scratch artifacts, not part of the deliverable.
