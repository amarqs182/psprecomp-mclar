# Midnight Club: L.A. Remix (USA) — PortMaster Port

Statically recompiled port of Midnight Club: L.A. Remix (USA) for PSP, built
with [psprecomp](https://github.com/sp00nznet/psprecomp) (v0.5.0, MIT). The
Allegrex MIPS code is translated ahead-of-time into native C for aarch64 and
runs natively on the RK3326 (R36S) under PortMaster.

## What this is

This is a **static recompilation**, not an emulator. The game's Allegrex MIPS
code has been translated to C ahead of time, compiled for aarch64, and linked
against a reimplementation of the PSP firmware surface (`sceKernel*`,
`sceGu*`, `sceCtrl*`, etc.). No emulator is required at run time.

## What you need

- A PortMaster device (R36S with ArkOS/dArkOS Enhanced)
- Your own copy of Midnight Club: L.A. Remix (USA) for PSP
- The ability to decrypt the PSP EBOOT (see "Decryption" below)

## Installation

1. Copy this port directory to your PortMaster `ports/` folder:

   ```
   ports/midnight-club-lar/
   ```

2. Build the `mc3` binary for aarch64 (see "Building" below) and place it at
   `ports/midnight-club-lar/mc3`.

3. Place your **decrypted** `EBOOT.ELF` where the launch script can find it
   (see "Launching" below).

4. Launch from the PortMaster GUI.

## Decryption

You must decrypt the game yourself from your own copy of the ISO. The toolkit
and this project do **not** provide decryption keys or decrypt on your behalf.

The decrypted `EBOOT.ELF` must be the unencrypted ELF32 MIPS module extracted
from `PSP_GAME/SYSDIR/EBOOT.BIN` on the disc.

**Never distribute the ISO, the decrypted ELF, or any extracted assets.**

## Launching

The launch script looks for `EBOOT.ELF` in:

1. `$MC3_EBOOT` (environment variable)
2. `ports/midnight-club-lar/../userdata/EBOOT.ELF`
3. `ports/midnight-club-lar/../bios/EBOOT.ELF`
4. `ports/midnight-club-lar/EBOOT.ELF`
5. `~/mc3/EBOOT.ELF`

You can override the render backend with `$MC3_RENDER`:

- `gles32` — OpenGL ES 3.2 (default, for RK3326/Mali-G31)
- `software` — software rasterizer (reference, no GPU)
- `null` — no rendering (benchmarking)

Example:

```sh
MC3_EBOOT=/path/to/EBOOT.ELF MC3_RENDER=gles32 ./ports/midnight-club-lar/"Midnight Club - L.A. Remix.sh"
```

## Building

The `mc3` binary is compiled from the statically-recompiled C generated by
`psprecomp allegrexrecomp emit`. Build steps (host or cross):

```sh
cd /path/to/Midnight\ Club\ -\ L.A.\ Remix\ \(USA\)

# Configure (aarch64 cross for R36S)
cmake -S . -B build-aarch64 -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=... \
  -DPPSPRECOMP_REAL_THREADS=ON

# Build
cmake --build build-aarch64 -j6 --target mc3

# Copy the binary into the port
cp build-aarch64/src/mc3/mc3 ports/midnight-club-lar/mc3
```

The host build (for testing without a device) uses native SDL2/GLES:

```sh
cmake -S . -B build -G Ninja -DPPSPRECOMP_REAL_THREADS=ON
cmake --build build -j6 --target mc3
./build/src/mc3/mc3 -e <decrypted-EBOOT.ELF> -r gles32
```

## Known issues

- **Tail-call stack overflow**: The emitter compiles some tail calls as plain
  C calls, causing C stack overflow in mutual-recursion code paths
  (functions `0x2EE75C` / `0x2EF5CC`). A tail-call optimization pass in
  `psprecomp`'s emitter is needed to fix this. The port may crash before
  reaching the title screen until that fix lands.
- **No texture support**: The render interface currently carries position +
  colour only; textured geometry draws as solid colour. Textures, CLUTs, and
  the VFPU transform pipeline are not yet implemented.
- **R36S untested**: No ADB access to the device; performance and stability
  on the RK3326/Mali-G31 are unverified.

## Rendering

- **Backend**: GLES 3.2 (required by Mali-G31; no Vulkan)
- **Display**: 640x480 window, PSP 480x272 letterboxed into 640x363 content
  area (58px top/bottom bars). No stretch-to-fill by default.
- **Backend selection**: `MC3_RENDER=gles32|software|null`

## Asset reduction

Asset reduction (language stripping, movie replacement, audio downsampling,
texture downscaling) is **not** included in this port. It is an optional,
user-side, measurement-gated post-processing step that operates on your own
decrypted copy only. See the root `README.md` for the reduction policy.
